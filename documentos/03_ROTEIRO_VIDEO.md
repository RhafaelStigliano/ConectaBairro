### 0:00–0:30 — Apresentação
“Olá, somos o grupo responsável pelo projeto ConectaBairro, uma plataforma integrada de apoio comunitário. Nosso cenário é o Bairro Uninove, uma comunidade fictícia criada para demonstrar a proposta.”

### 0:30–1:20 — Descrição e problema
“O projeto parte de uma situação em que avisos, pedidos de ajuda, eventos e informações de comércios ficam espalhados em diferentes canais. Isso pode dificultar a organização e o acesso às informações. Nossa proposta é reunir esses recursos em um ambiente digital.”

### 1:20–2:00 — Objetivo e funcionalidades
“O objetivo é aproximar moradores e facilitar a colaboração. A plataforma foi planejada com áreas de avisos, pedidos de ajuda, eventos e comércio local. Nesta versão demonstrativa, priorizamos o acesso de usuários e o gerenciamento de pedidos de ajuda.”

### 2:00–2:40 — Tecnologias e DevOps
“O sistema foi desenvolvido em PHP, com banco de dados MySQL, HTML e CSS. Para organização do código, utilizamos Git e GitHub [somente se isso tiver sido realizado], registrando as alterações do projeto e mantendo o código-fonte organizado.”

### 2:40–5:50 — Demonstração prática
1. Mostrar a tela de login.
2. Criar uma conta de demonstração ou entrar com usuário já cadastrado.
3. Mostrar o painel.
4. Cadastrar um pedido de ajuda.
5. Mostrar o pedido na lista.
6. Editar o pedido e alterar o status.
7. Mostrar a alteração.
8. Excluir o pedido e confirmar a exclusão.
9. Mostrar que o registro não aparece mais.

### 5:50–6:30 — Banco de dados
“Nosso banco possui cinco tabelas: usuarios, avisos, pedidos_ajuda, eventos e comercios. Elas foram planejadas para armazenar os dados principais da plataforma. Aqui mostramos os comandos CREATE TABLE utilizados.”

### 6:30–7:00 — Conclusão
“O projeto permitiu aplicar conhecimentos de desenvolvimento web e banco de dados em uma proposta voltada à colaboração comunitária. O protótipo demonstra o fluxo de cadastro, login e gerenciamento de pedidos de ajuda e pode ser ampliado com os demais módulos. Obrigado!”
