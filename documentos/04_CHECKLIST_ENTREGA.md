# Checklist final do grupo

## Antes de programar
- [ ] Confirmar nome completo e RA de cada integrante.
- [ ] Confirmar semestre e turma.
- [ ] Definir quem será responsável por cada parte.
- [ ] Instalar XAMPP e importar database.sql.

## Testes obrigatórios da demonstração
- [ ] Cadastro de usuário.
- [ ] Login com senha correta.
- [ ] Login com senha incorreta.
- [ ] Inclusão de pedido de ajuda.
- [ ] Visualização do pedido.
- [ ] Alteração do pedido/status.
- [ ] Exclusão com confirmação.
- [ ] Capturar imagens reais do sistema funcionando.

## Documento escrito
- [ ] Preencher capa e folha de rosto com todos os nomes e RAs.
- [ ] Atualizar semestre e ano.
- [ ] Inserir link real do GitHub.
- [ ] Inserir o SQL integral das cinco tabelas.
- [ ] Completar DevOps com o que foi realmente feito.
- [ ] Inserir cinco livros da Biblioteca Digital da Uninove em ABNT.
- [ ] Revisar conclusão após os testes.

## Banner
- [ ] Preencher todos os integrantes e RAs.
- [ ] Inserir diagnóstico como cenário fictício/simulado.
- [ ] Inserir objetivo, proposta de melhoria e comunidade impactada.
- [ ] Inserir relatório final baseado nos testes reais.
- [ ] Inserir duas capturas reais do sistema em funcionamento.
- [ ] Exportar em PDF.
- [ ] Cada aluno enviar individualmente pela Central do Aluno > Meus Links > Projetos.

## Vídeo
- [ ] Duração de 5 a 7 minutos.
- [ ] Apresentar o projeto.
- [ ] Explicar problema, objetivo e tecnologias.
- [ ] Mostrar login e CRUD funcionando.
- [ ] Mostrar brevemente as cinco tabelas SQL.
- [ ] Apresentar conclusão.
